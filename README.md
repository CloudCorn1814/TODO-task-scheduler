# Планировщик задач (TODO-сервер)

## Описание проекта
Проект представляет собой учебный веб-сервер для управления задачами (TODO-лист).  
REST API + SQLite. Позволяет добавлять, редактировать, удалять и отмечать задачи.  
Фронтенд на HTML/JS был предоставлен в качестве исходных данных и подключается к API.

## Структура проекта
.
├─ internal/
│  ├─ api/        # обработчики API
│  ├─ db/         # База данных и функции для работы с ней
│  └─ server/     # конфигурационный файл и сервер
├─ web/           # фронтенд
├─ tests/         # автотесты
├─ go.mod / go.sum
└─ main.go

## Инструкция по локальному запуску
1. Клонировать репозиторий:
git clone <repo-url>
cd todo-task-scheduler
2. Установить зависимости:
   go mod tidy
3. Запустить сервер: 
TODO_PORT=7540 TODO_DBFILE=./scheduler.db go run .
4. Открыть в браузере http://localhost:7540/

## Инструкция по запуску тестов
1. В файле tests/settings.go указать следующие значения:
// для порта сервера (будет задано по умолчанию)
var Port = 7540
// путь к базе данных (будет задан по умолчанию)
var DBFile = "../scheduler.db"
// для тестирования поиска по заголовку,комментарию или дате (будет задано по умолчанию)
var Search = true

2. Запустить тесты:
TODO_PORT=7540 TODO_DBFILE=./scheduler.db go test ./tests
